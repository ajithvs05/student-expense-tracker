# 💰 Student Expense Tracker

A simple Python-based expense management application designed for students.

The project helps students record their daily expenses, organize them into categories, track their budget, and generate a spending report.

## ✨ Features

* 💵 Add and save expenses
* 🏷️ Categorize expenses
* 📋 View all expenses
* 🧮 Calculate total spending
* 💰 Set a monthly budget
* 📊 Check remaining budget
* 📈 Generate a spending report
* 💾 Store expense data in a file

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/student-expense-tracker.git
```

Open the project folder:

```bash
cd student-expense-tracker
```

Run the application:

```bash
python expense_tracker.py
```

To generate the spending report:

```bash
python report.py
```
